# 公式目录：World Engine、Model Workspace、Practice 与 EconBench

**公式条目状态：** 除标作 `observed` 的案例数字外，所有参数和测试均为 `synthetic_calibration` 或教学示例。
**单位约定：** `P` 是 GCU/物理单位，`Q` 是物理单位/期，`Y` 是实际或名义产出（必须在同一式中固定），利率/通胀/份额若写作小数则在数据入式前由百分比除以 100。测试例只验证代数，不证明现实因果。
**权威可访问来源：** 基础微观/宏观和机制使用开放教材 [CORE Econ](https://www.core-econ.org/the-economy/)（`SRC-CORE-2026`）；债务使用 [IMF Debt Dynamics 技术手册](https://www.imf.org/-/media/websites/imf/imported-full-text-pdf/external/pubs/ft/tnm/2010/_tnm1002.pdf)；国际传导使用 [IMF WEO 外部失衡章节](https://www.elibrary.imf.org/abstract/book/9781589066267/ch03.xml) 和 [2015 年不完全传导推导](https://www.elibrary.imf.org/display/book/9781513520735/ch003.xml)；计量识别使用 [Mastering ’Metrics 配套资料](https://www.mostlyharmlesseconometrics.com/)（`SRC-NBER-OLS`）。

## 使用总则

- 每一张卡都列出 `公式 → 推导/来源 → 变量及单位 → 假设/边界 → 典型范围 → 数值测试`；引擎不得只取公式而略过边界。
- 使用 `dln`、`Δln` 的弹性/传导式时，输入是比例（10% = 0.10），输出也是比例；显示时再乘 100 变成百分点或百分比。
- 真实资料与合成校准分开：公式的代数是通用教学工具；其参数不是现实国家的结构估计。

## 实装检查清单

1. 把每张卡的测试例加入单元测试；输入/输出单位若不符，拒绝计算。
2. 对宏观和政策结果输出“机制方向、参数范围、状态条件”，而非“预测”。
3. 对国际式固定汇率报价方向、储备记账符号与百分比/小数转换，避免最常见的正负号错误。
4. 对计量模块显示识别假设检查和失败原因；没有公开、可追溯数据时只允许合成练习。
