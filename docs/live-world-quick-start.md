# EconMind OS Live World 使用指南

Live World 是一个独立运行的课堂世界经济模拟。教师或学校负责人创建房间后，学生通过专属链接和玩家码进入；学生不需要注册或登录常规 EconMind OS 账号。

## 一、谁可以使用

- **组织者（Host）**：Teacher、School Leader 或 Platform Admin。组织者必须先登录 EconMind OS，才可创建和管理房间。
- **玩家（Player）**：学生只需使用组织者发出的房间链接和 **Player code** 进入，不需要主平台账号。
- **管理者（Administrator）**：使用 **Administrator code** 进入同一房间的主控台。请仅由教师或课堂助教保管该代码。

Teacher 和 School Leader 只能查看、管理自己创建的 Live World 房间；Platform Admin 可查看全部房间。

## 二、组织者课前准备

建议在课前 10–15 分钟完成下列事项：

1. 使用电脑和稳定网络登录 EconMind OS；如需投屏，提前打开主控台页面。
2. 在账户菜单中选择 **Live World rooms**，填写房间名称、活动时长和玩家人数上限，然后创建房间。
3. 创建成功后，立即保存三项信息：**独立房间链接、Player code、Administrator code**。邀请码只在创建时显示一次，离开页面后不能再次查看。
4. 将“链接 + Player code”发送给学生；不要将 Administrator code 发到班级群或学生群。
5. 建议教师另开一个浏览器窗口、无痕窗口或另一台设备，打开同一链接并输入 Administrator code，作为课堂主控台。这样不会与学生端的临时身份混淆。

可直接转发给学生的通知模板：

> 你将参加 EconMind Live World 课堂模拟。请在活动开始前 5 分钟打开以下链接，并输入自己的显示名称和 Player code。请勿分享代码或使用他人姓名。进入后按提示选择国家与职位，等待教师宣布开始。\
> 链接：`[由教师粘贴]`\
> Player code：`[由教师粘贴]`

## 三、组织者 / 管理端操作流程

### 1. 创建并邀请

创建房间后，主控台会显示房间状态和已加入人数。学生可以在活动开始前进入并选择尚未被占用的国家与职位；如尚未准备好，请先不要开始房间。

如果链接或玩家码泄露，最稳妥的处理方式是停止使用该房间并创建新的房间，再发送新的邀请信息。不要在公开网页、社交媒体或截图中展示 Administrator code。

### 2. 课堂开始

确认人数、角色分配和网络情况后，在 Administrator 主控台开始活动。开始后，学生进入各自的政策工作区；课堂中的消息、协议、危机状态和已发布决策会在房间内同步显示。

教师可根据课堂节奏使用主控台中的开始、暂停、继续或结束控制。暂停适合用于解释规则、组织国家间协商或处理断线；恢复后模拟将继续按房间节奏运行。

### 3. 课堂中建议

- 先用 2–3 分钟说明：每位学生只代表自己选择的职位，决策会影响本国及其他国家。
- 鼓励学生先保存草稿，再在本组达成意见后发布；发布前应确认数值和政策方向。
- 需要谈判时，可暂停模拟并给各国短暂讨论时间，再恢复继续。
- 不要代替学生在玩家端做出决策；主控台用于组织课堂，而不是替代各职位的选择。

### 4. 结束与复盘

活动结束后，组织者可让学生留在结果页，结合排行榜、国家结果、协议和危机处理过程进行讨论。推荐用以下问题复盘：哪些政策优先级发生了冲突？哪些跨国协作有效？信息不完整如何影响决策？

结束房间后请勿继续将旧 Player code 用于下一节课；每次课堂建议创建新的房间和新邀请码。

## 四、学生 / Player 端操作流程

1. 打开教师发来的独立链接，输入显示名称和 **Player code**。显示名称应便于课堂识别，不要填写手机号、住址或其他敏感个人信息。
2. 在候场阶段选择一个未被占用的国家和职位。若目标位置已被占用，请选择其他空位并向教师说明。
3. 等待教师开始。开始后，进入自己的政策工作区，阅读当前局势、消息和待处理事项。
4. 按页面提示调整政策或回应事项。建议先保存草稿；确认后再发布。每位玩家只能处理自己职位权限内的决策。
5. 关注国家间的协议、消息与危机更新，并在需要时与同国成员或其他国家协商。
6. 教师结束房间后，查看结果与排行榜，参与课堂复盘。

## 五、常见问题与课堂规则

**提示代码无效怎么办？** 先确认输入的是 Player code，而不是 Administrator code；检查是否复制了多余空格。仍无法进入时联系教师，不要反复猜测代码。

**刷新页面后还能继续吗？** 可以尝试使用原链接重新进入。若位置已被保留或页面显示异常，请联系教师安排处理；不要使用其他同学的显示名称或代码。

**为什么不能选择某个职位或发布某项政策？** 该位置可能已被占用，或该事项不属于你的职位权限。请阅读页面提示并向教师确认。

**是否需要 EconMind OS 账号？** 不需要。Live World 使用独立的临时课堂会话，不会把学生的临时参与身份连接到常规 EconMind OS 账号。

**安全与隐私提醒**：Player code 仅用于本次课堂进入房间；Administrator code 可控制房间，必须保密。学生应只使用课堂显示名称，不要在名称、消息或协议中提交敏感个人信息。
