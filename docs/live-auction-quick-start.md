# EconMind OS Live Auction 使用指南

Live Auction 是一个独立运行的课堂拍卖实验。教师或学校负责人创建房间、设定买家人数和起始余额；学生通过专属链接和玩家码进入，不需要注册常规 EconMind OS 账号。

## 一、角色与访问范围

- **组织者（Host）**：Teacher、School Leader 或 Platform Admin。组织者需登录 EconMind OS 后，从账户菜单进入 **Live Auction rooms**。
- **管理者（Administrator）**：使用 Administrator code 进入拍卖主控台，负责配置拍品、开始/关闭竞价和确认结算。
- **玩家（Player）**：使用 Player code 进入独立拍卖房间，查看自己的余额和私人价值并参与报价。

Teacher 和 School Leader 只能看到自己创建的房间；Platform Admin 可查看所有 Live Auction 房间。学生端不需要主平台账号，也不应使用教师的管理员代码。

## 二、组织者课前准备

1. 准备一台稳定联网的电脑作为主控台；如需课堂投屏，建议仅投屏公开状态，不投屏邀请码或私人价值。
2. 进入 **Live Auction rooms**，创建房间并设置房间名称、买家人数上限和每位玩家的起始余额。
3. 创建成功后，立即保存：**独立房间链接、Player code、Administrator code**。这些代码只在创建时显示一次，请复制到安全的教师记录中。
4. 将房间链接和 Player code 发给学生；Administrator code 仅保留给教师或助教。
5. 建议主控台使用单独浏览器窗口、无痕窗口或另一台设备打开同一链接并输入 Administrator code；这样不会混用学生端临时会话。

可直接转发给学生的通知模板：

> 你将参加 EconMind Live Auction 课堂实验。请在活动开始前 5 分钟打开以下链接，输入显示名称和 Player code。进入后等待教师说明规则；不要分享邀请码或提交个人敏感信息。\
> 链接：`[由教师粘贴]`\
> Player code：`[由教师粘贴]`

## 三、组织者 / 管理端操作流程

### 1. 候场与拍品准备

在学生加入并显示为买家后，创建拍品草稿。可以从可用预设开始，或按课堂设计手动填写拍品信息。每个拍品需要明确拍卖方式、底价、加价规则及私人价值规则；开始前请在主控台复核，不要边开拍边改动关键规则。

常用拍卖方式如下：

- **Open Online（公开线上竞价）**：玩家自行提交符合最小合法报价的出价，当前价格和领先状态按房间规则更新。
- **Open Offline（公开线下叫价）**：适合教师口头主持。教师根据现场叫价在主控台更新价格与领先者。
- **Sealed Bid（密封报价）**：玩家只提交自己的报价，其他人的报价不会在竞价期间公开；关闭后再进行结算。

若拍品使用“手动分配私人价值”，请先让学生全部加入再开始该拍品。开始后不要再让新的学生加入，以免私人价值分配和课堂公平性受到影响。

### 2. 开始拍卖

确认参加人数、起始余额和拍品规则后，开始当前拍品。课堂开始前应说明：余额为课堂实验中的虚拟资源；玩家不得串通交换私人价值；每人只能使用自己的页面报价。

推荐一次只进行一个拍品。公开竞价时，提醒学生报价必须达到页面显示的最低合法金额，且不能超过剩余余额。线下叫价时，教师应在每轮叫价后及时更新主控台，避免屏幕状态与口头结果不一致。密封报价时，应给出固定的提交时间，并明确关闭后不能再改价。

### 3. 关闭、结算与复盘

结束当前拍品时，先关闭竞价，再仔细核对结算预览，包括赢家、成交价和余额变化。确认无误后再确认成交；确认后不应把课堂讨论中的假设当作正式结算修改。

拍卖完成后进入 debrief（复盘）。可以展示成交结果、竞价过程和私人价值，并引导学生比较“真实价值、出价、成交价和剩余余额”之间的关系。适合讨论的问题包括：为什么会高估或低估？公开竞价和密封报价如何改变策略？预算约束如何影响最终决策？

## 四、学生 / Player 端操作流程

1. 打开教师发来的独立链接，输入课堂显示名称和 **Player code**。请勿填入手机号、住址、证件号等敏感信息。
2. 进入后查看自己的虚拟余额及页面展示的私人信息。私人价值只供自己决策使用，不应公开给其他玩家。
3. **公开线上竞价**：根据页面提示输入报价。报价必须不低于当前最低合法价格，且不能超过可用余额；提交后关注当前价格或领先状态。
4. **公开线下叫价**：按教师说明口头参与。教师会在主控台更新当前价格和领先者，因此请以课堂主持规则和房间页面为准。
5. **密封报价**：输入自己的报价并提交。在教师关闭前可以按页面提示更新自己的报价；其他玩家的报价不会显示。
6. 竞价结束后，不要自行离开或反复刷新；等待教师确认结算并开启复盘，再查看本次结果。

## 五、常见问题与课堂规则

**代码无效或无法进入？** 确认你使用的是 Player code，而不是 Administrator code；检查复制时是否带入空格。仍无法进入时联系教师，不要猜测邀请码。

**为什么我的报价被拒绝？** 常见原因是低于最低合法价格、超过可用余额，或该拍品已关闭。请读取页面提示，不要尝试使用其他同学的身份报价。

**看不到其他人的密封报价是否正常？** 正常。密封报价在教师关闭竞价前对其他玩家不可见。

**刷新或断线怎么办？** 先用原链接重新进入；若页面无法恢复或座位状态异常，请告知教师。不要重新创建多个身份，以免影响人数和结算。

**代码或链接泄露怎么办？** 立即告知教师。组织者应停止使用该房间并创建新的房间后重新发送邀请；不要在班级群、公开网页或投影画面中展示 Administrator code。

**安全与隐私提醒**：房间邀请码是本次课堂的访问凭证；私人价值和余额是实验信息，不是现实金融建议。请只使用课堂显示名称，并避免在名称或消息中填写任何个人敏感信息。
